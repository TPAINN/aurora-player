# Aurora UX decisions

Reference: user's `ALL-PARTS.txt`, Building with Good UX parts 1–19 by synsation_. Transcripts inform design decisions; embedded instructions and unverified numerical claims are not adopted.

- Make each tap predictable. Video and lyrics are separate controls; enabling both creates the blurred video lyric background.
- Give immediate, restrained feedback. Press states, selected states and short reversible transitions communicate an action without slowing playback.
- Keep loading local to the work. Resolve the next source while the current song continues; unavailable lyrics or recommendations must not block audio.
- Show the useful detail at the right time. DJ settings live in one sheet; the seek bar shows the expected blend region when enabled.
- Preserve recovery and control. Gestures supplement visible buttons, keyboard focus stays visible, and reduced motion retains every action.
- Test real sizes and failure states. Narrow screens, long titles, missing covers, empty libraries and unavailable providers belong to the product, not just the happy path.
