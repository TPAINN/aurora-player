# Aurora Player

## Platform
Responsive React web app / installable PWA, mobile and desktop.

## Purpose
Search for music and listen with immersive artwork and genuinely synchronized lyrics. No accounts, no application advertising. External playback providers control their own availability and advertising.

## Audience and constraints
Music listeners using phones or desktop browsers. Local favorites and queue; no invented social counts or audio-quality claims. Preserve search, playback, seeking, video mode and lyric offset controls. Metadata and artwork come from actual music catalogue results.

## Brand commitments
The user's nine image references are binding: full-bleed mobile artwork, translucent pill controls, a desktop cover carousel, artwork-driven atmosphere, large white active lyrics. User approved this direction and delegated implementation decisions on 2026-09-24.
